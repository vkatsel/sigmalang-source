# sigmaLang

A programming language featuring brainrot/sigma-themed keywords, UTF-8 emoji operators, and explicit immutability semantics.

## Project Information
- **Course**: Languages and Compilers Design (CS400)
- **Author**: Vladyslav Katsel
- **Stage**: Stage 1 — Language Design, Lexer and Parser
